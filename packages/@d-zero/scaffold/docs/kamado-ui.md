# Kamado UI でページの情報を編集する

Kamado UI は、サイトの全ページを1つの表で見て、タイトルや URL などをその場で書き換えられる画面です。コードを開かずに、ページの情報を整理できます。

## できること、できないこと

| できること                                   | できないこと                   |
| -------------------------------------------- | ------------------------------ |
| タイトルなど、ページの情報（メタ）の書き換え | ページの新規作成・削除・複製   |
| レイアウトの選び直し                         | 本文の編集                     |
| URL の変更                                   | デザインやコンポーネントの変更 |
| ファイルの置き場所の変更                     | コミット、公開                 |
| 検索、並べ替え、列の入れ替え                 |                                |

できないことは、エンジニアか AI に依頼します。

## 始める

ターミナルでプロジェクトのフォルダーを開き、次を実行します。

```sh
yarn ui
```

ブラウザが開き、表が出ます（開かないときはhttp://localhost:8001/を開きます）。終わるときは、ターミナルで`Ctrl+C`を押します。

サイトの表示を確かめる`yarn dev`（ http://localhost:8000/ ）とは、別のターミナルで同時に動かせます。

## 画面の見かた

1行が1ページです。

| 列          | 内容                                                  |
| ----------- | ----------------------------------------------------- |
| `url`       | ページの URL                                          |
| `virtual`   | ファイルの無いページかどうか（ふつうは空）            |
| `inputPath` | ページのファイルの置き場所（`__assets/htdocs`から）   |
| `title`     | ページのタイトル。`<title>`、見出し、パンくずに出ます |
| `layout`    | ページの枠組み（トップページ用、下層ページ用など）    |
| そのほか    | ページに書かれている情報が、1つずつ列になります       |

ヘッダーには、今のブランチが`main @ 51df987`の形で出ます。

## 値を書き換える

1. 書き換えたいセルをダブルクリックします（キーボードでは、矢印で移動して`Enter`）
2. 値を入力します
3. `Enter`を押すか、別のセルをクリックすると保存されます。`Escape`で取り消せます

- 保存すると、すぐにファイルに書き込まれます。保存ボタンも確認の画面もありません
- `layout`は、一覧から選びます
- チェックボックスは、クリックするたびに切り替わります
- セルで`Delete`を押すと、その情報を消します
- 表に無い情報を足すときは、「キーの追加」を使います

## URL やファイルの場所を変える

`url`か`inputPath`のセルを書き換えると、ページのファイルが新しい場所へ移ります。

| 書き換えるセル | 書きかたの例                                |
| -------------- | ------------------------------------------- |
| `url`          | `/company/`、`/company/history.html`        |
| `inputPath`    | `company/`（`company/index.tsx`になります） |

**変える前に知っておくこと**

- ほかのページやメニューからのリンクは、**自動では直りません**。変えたあとに、エンジニアか AI へ「リンクを直して」と伝えます
- `/a/`を`/b/`に変えても、`/a/`の下のページは動きません。下のページは1つずつ変えます
- 公開済みのページの URL を変えると、検索結果やブックマークからたどり着けなくなります。変える前に担当者へ相談します
- 同じ URL のページがすでにあるときなどは、理由が表示されて、変更されません

## 探す、並べ替える

- **探す**: 検索欄に入力すると、URL と値に含まれるページだけが残ります
- **並べ替える**: 列の見出しの`⋮`から、昇順・降順を選びます
- **列を動かす**: 見出しをドラッグします。`⋮`から「左に固定」を選ぶと、横にスクロールしても残ります
- **表示件数**: 1画面に 100・500・1,000・5,000 件から選べます

これらの設定は、あなたのパソコンに保存されます（`~/.config/kamado/ui-settings.json`）。ほかの人には影響しません。

## 書き換える前の値に戻す

最後のコミットから値が変わったセルには、左端に色の帯が出ます（青は変更、緑は追加、赤は削除）。帯をクリックすると、今の値と元の値が表示され、元の値に戻せます。

## 編集が終わったら

1. `yarn dev`の画面（ http://localhost:8000/ ）を再読み込みして、表示を確かめます
2. URL やファイルの場所を変えたときは、エンジニアか AI にリンクの修正を依頼します
3. 変更の保存（コミット）を、エンジニアか AI に依頼します。AI には`/git`と伝えます

## 困ったとき

| 起きたこと                                    | すること                                                                             |
| --------------------------------------------- | ------------------------------------------------------------------------------------ |
| 「別の場所で変更された」と出て保存されない    | ほかの人か AI が同じファイルを変えています。表が読み直されるので、もう一度編集します |
| セルが編集できない                            | セルに理由が出ます。その内容をエンジニアに伝えます                                   |
| ファイルを直接変えたのに、表が変わらない      | 「読み直す」ボタンを押します                                                         |
| `port 8001 is already in use`と出て始まらない | すでに`yarn ui`が動いています。動いているほうを使うか、`Ctrl+C`で止めます            |
| `yarn ui`を実行するとエラーで止まる           | ページの書きかたに誤りがあります。表示されたメッセージをエンジニアに伝えます         |
