# Kamado UI でページの情報を編集する

Kamado UI は、サイトの全ページを1つの表で見て、タイトルや URL などをその場で書き換えられる画面です。コードを開かずに、ページの情報を整理できます。

## できること、できないこと

| できること                                   | できないこと                     |
| -------------------------------------------- | -------------------------------- |
| タイトルなど、ページの情報（メタ）の書き換え | 本文の編集                       |
| レイアウトの選び直し                         | デザインやコンポーネントの変更   |
| URL の変更                                   | ページの複製                     |
| ファイルの置き場所の変更                     | 削除したページの、画面からの復元 |
| ページの追加と削除                           | コミット、公開                   |
| 検索、並べ替え、列の入れ替え                 |                                  |

できないことは、エンジニアか AI に依頼します。

## 始める前に

- **書き換えは、すぐにファイルに保存されます。** 保存ボタンはありません。セルを書き換えたまま別のウィンドウに切り替えるだけでも、保存されます。確認の画面が出るのは、ページを追加・削除するときだけです
- **ページを削除すると、ページの本文も一緒に消えます。** 画面からは戻せません（コミットしてあれば、エンジニアか AI が Git から戻せます）
- 作業用のブランチで始めます。画面の上に出るブランチ名が`main`のときは、編集する前にエンジニアへ相談します
- 初めて使うときは、プロジェクトのフォルダーで`yarn`を実行して、必要なパッケージを入れておきます

## 始める

ターミナルでプロジェクトのフォルダーを開き、次を実行します。

```sh
yarn dir
```

ブラウザが開き、表が出ます。開かないときは、ブラウザで<http://localhost:8001/>を開きます。終わるときは、ターミナルで`Ctrl+C`を押します。

画面が英語で出たときは、画面の「Language/言語」で日本語を選びます。

サイトの表示を確かめる`yarn dev`（ http://localhost:8000/ ）とは、別のターミナルで同時に動かせます。

## 画面の見かた

1行が1ページです。

| 列           | 内容                                                  |
| ------------ | ----------------------------------------------------- |
| `url`        | ページの URL                                          |
| `virtual`    | ふつうは空です。触りません                            |
| `inputPath`  | ページのファイルの置き場所                            |
| `order`      | ページの並び順。読み取り専用です                      |
| `outputPath` | ビルドしたときの出力ファイル。読み取り専用です        |
| `parent`     | 1つ上のページの URL。読み取り専用です                 |
| `depth`      | 階層の深さ。読み取り専用です                          |
| `title`      | ページのタイトル。`<title>`、見出し、パンくずに出ます |
| `layout`     | ページの枠組み（トップページ用、下層ページ用など）    |
| そのほか     | ページに書かれている情報が、1つずつ列になります       |

画面の上には、今のブランチが`topic-branch @ 51df987`の形で出ます。表の下には、小さなラベルや色の帯の意味が書いてあります。

## 値を書き換える

1. 書き換えたいセルをダブルクリックします（キーボードでは、矢印で移動して`Enter`）
2. 値を入力します
3. `Enter`を押すと保存されます。別のセルをクリックしたときや、別のウィンドウに切り替えたときも保存されます。保存したくないときは、先に`Escape`を押して取り消します

- `layout`は、一覧から選びます
- チェックボックスは、クリックするたびに切り替わります
- 表に無い情報を足すときは、「キーの追加」を使います
- セルで`Delete`を押すと、その情報を消します（Mac は`fn`+`delete`）。確認の画面は出ません。ただし`url`のセルで押すと、ページの削除になります（下の「ページを追加する・削除する」）

## ページを追加する・削除する

**追加**

1. 画面の上の「ページの追加」を押します
2. `url`と`inputPath`を入力します。`inputPath`を入れると、その場所にページのファイルが作られます（ファイル名は拡張子まで書きます。拡張子は`.tsx`、`.jsx`、`.html`、`.htm`）。`url`を空にすると、`inputPath`の場所から決まる URL になります

作られるのは、何も表示しない空のページです（`.tsx`と`.jsx`は、何も描かない部品だけのファイル）。タイトルやレイアウトは、あとから表のセルで「キーの追加」から入れます。本文は、エンジニアか AI に依頼します。

**削除**

- `inputPath`のセルを空にして`Enter`を押すと、「ファイルを無くしますか」という確認が出ます。「削除」を選ぶと、ページのファイルと同じ名前の`.json`が消えます
- `url`のセルを空にしても、同じ確認が出ます
- 確認の画面には、消えるファイルの名前と、**ページの本文も一緒に失われる**ことが出ます。「キャンセル」が最初に選ばれています

「仮想化」は、ファイルだけを消して URL とタイトルを残す操作です。このプロジェクトは設定していないので、使えません。選ぶ必要はありません。

## URL やファイルの場所を変える

`url`か`inputPath`のセルを書き換えると、ページのファイルが新しい場所へ移ります。

| 書き換えるセル | 入力する値の例          | 結果                                      |
| -------------- | ----------------------- | ----------------------------------------- |
| `url`          | `/company/`             | URL が`/company/`になります               |
| `url`          | `/company/history.html` | URL が`/company/history.html`になります   |
| `inputPath`    | `company/`              | ファイルが`company/index.tsx`へ移ります   |
| `inputPath`    | `company/history`       | ファイルが`company/history.tsx`へ移ります |

- `inputPath`には、表に出ているのと同じ書きかた（`__assets/htdocs`の中での場所）で入力します。`__assets/htdocs/`は付けません
- `url`は`/`で始めます。フォルダーの URL は`/`で終わらせます（`/company`や`/company/index.html`は受け付けられません）
- ファイルの種類（`.tsx`、`.html`）は変えられません

**変える前に知っておくこと**

- ほかのページやメニューからのリンクは、**自動では直りません**。変えたあとに、エンジニアか AI へ「リンクを直して」と伝えます
- `/a/`を`/b/`に変えても、`/a/`の下のページは動きません。下のページは1つずつ変えます
- 公開済みのページの URL を変えると、検索結果やブックマークからたどり着けなくなります。変える前に担当者へ相談します
- 同じ URL のページがすでにあるときなどは、表の上に理由（英語）が出て、変更されません
- 変えた URL やファイルの場所を元に戻すときは、元の値を入力し直します（次の「元の値に戻す」は使えません）

## 探す、並べ替える

- **探す**: 検索欄に入力すると、入力した文字が URL か値に含まれるページだけが残ります
- **並べ替える**: 列の見出しの`⋮`から、昇順・降順を選びます
- **列を動かす**: 見出しをドラッグします。`⋮`から「左に固定」を選ぶと、横にスクロールしても残ります
- **表示件数**: 「1 ページの行数」で、100・500・1,000・5,000 件から選べます

並べ替え・列の並び・表示件数・言語は、あなたのパソコンに保存されます。次に開いたときも同じになり、ほかの人には影響しません。

## 元の値に戻す

最後のコミットから値が変わったセルには、左端に色の帯が出ます（青は変更、緑は追加、赤は削除）。帯をクリックすると、今の値と元の値が表示され、元の値に戻せます。

- URL やファイルの場所を変えたページは、新しいページとして扱われ、行のすべてのセルが緑になります。このページの帯からは戻せません
- 帯が出るのは、プロジェクトが Git で管理されていて、コミットが1つ以上あるときだけです

## 編集が終わったら

1. `yarn dev`の画面（ http://localhost:8000/ ）を再読み込みして、表示を確かめます
2. URL やファイルの場所を変えたときは、エンジニアか AI にリンクの修正を依頼します
3. 変更の保存（コミット）を、エンジニアか AI に依頼します。AI には`/git`と伝えます

## 困ったとき

| 起きたこと                                    | すること                                                                                                               |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 「別の場所で変更された」と出て保存されない    | ほかの人か AI が同じファイルを変えています。表が読み直されるので、もう一度編集します                                   |
| セルが編集できない                            | 表の上に理由（英語）が出ます。その内容をエンジニアに伝えます                                                           |
| ファイルを直接変えたのに、表が変わらない      | 「読み直す」ボタンを押します                                                                                           |
| `port 8001 is already in use`と出て始まらない | すでに`yarn dir`が動いているか、ほかのソフトが同じ番号を使っています。`yarn dir --port 8002`で、別の番号で始められます |
| `yarn dir`を実行するとエラーで止まる          | プロジェクトのフォルダーで実行しているかを確かめます。合っていれば、表示されたメッセージをエンジニアに伝えます         |
